Four stages, one cap chain

Every roadmap stage claims a skill. What it can actually deliver is capped by the stage beneath it — this page maps each control to the failure it reproduces.

Honest limits. Thresholds and the +30 rise are model choices, not measurements. The claim is the shape: a skipped step sags everything above it.

What this demo proves

Choose Skip the basics — Basics 10, everything else 95 — then Run the demo: both rehearsed events pass. Now Ship it: the deck walks all eight production events and the build collapses on retry-storm, the first event defended by a stage you skipped. Three undefended events stamp the run CRASHED.

The controls

Features and what each one proves

01

Claimed-skill sliders

Four sliders set what each stage claims — the number on the roadmap checklist.

Proves
a claim is not competence — the staircase re-grades every claim.
Key detail
sliders clamp 0–100; changing one re-runs the whole cap chain.
02

The cap chain

effective[i] = min(claimed[i], effective[i-1] + 30) — each step's real height is capped by the step below.

Proves
a skipped stage sags every stage above it, not just itself.
Key detail
Basics 10 → LLMs cap 40 → RAG cap 70 → Agents cap 100; claimed 95 meets a hollow middle.
03

Hollow steps

Where claimed exceeds the cap, the step renders as a dashed outline — it cannot hold weight.

Proves
top-heavy builds look tall and stand on nothing.
Key detail
sag = claimed − effective is printed on each step.
04

Run the demo

Walks only schema-drift and stale-chunk — the rehearsed events.

Proves
a rehearsed happy path passes on a top-heavy build every time.
Key detail
both events are defended by stages the preset maxed.
05

Ship it

Walks the full eight-event deck; each event is defended by exactly one stage's effective skill.

Proves
production supplies the events the demo never rehearsed.
Key detail
retry-storm (basics, threshold 40) is where a skipped floor first gives way.
06

The CRASHED stamp

The ship absorbs two undefended events; the third flips the verdict.

Proves
production tolerates near-misses — it does not tolerate a missing floor.
Key detail
SHIP_BUDGET = 3; crashedAt records the first breach.

Architecture

How the lab is built

UISliders, staircase rendering, and the event-walk animation.public/app.js

Run locally

Inspect the evidence

npm test            # cap-chain unit tests + server e2e
npm run staircase   # CLI: claimed vs effective for every preset
npm run check       # tests
npm start           # serve the lab on :3000

Or ask the server directly: /api/assess?basics=10&llms=95&rag=95&agents=95 returns the full ladder plus both verdicts.

Limits

What this demo does not claim

  • Skill scores and thresholds are illustrative, not measured.
  • The +30 rise is a modeling choice; real dependencies between skills aren't linear.
  • Each event is defended by exactly one stage — real incidents span layers.
  • A SHIPPED verdict means the deck was survived, not that a system is correct.
